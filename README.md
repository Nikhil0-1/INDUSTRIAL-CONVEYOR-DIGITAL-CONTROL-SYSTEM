# INDUSTRIAL-CONVEYOR-DIGITAL-CONTROL-SYSTEM

Professional engineering-grade 3D simulation website for an Industrial Conveyor Digital Control System — a Digital Electronics Complex Engineering Project.

## Features
- Real-time 3D conveyor simulation (Three.js / React Three Fiber)
- Finite State Machine (FSM) with animated state diagram
- 4-to-2 Priority Encoder with truth table
- Product counting with edge detection
- Even Parity error detection
- Emergency stop & fault handling
- Digital signal oscilloscope monitor
- Predefined test scenarios with PASS/FAIL
- Auto demo & step-by-step mode
- Viva/Presentation mode
- Fully responsive (desktop + mobile)

## Tech Stack
- React + TypeScript + Vite
- Three.js / React Three Fiber / Drei
- Zustand (state management)
- Tailwind CSS
- Framer Motion

## Getting Started
```bash
npm install
npm run dev
```
